**The short version:** every platform runs the same kind of machine, but each one weights different actions. YouTube leans on watch time and satisfaction, TikTok on completion, Instagram Reels on reshares and watching through, and X on replies, quotes and shares. A post that won on one platform needs rebuilding for the next, not just re-uploading.

## Cross-posting without getting buried

1. **Export clean.** Instagram names other apps' watermarks as something that limits Reels reach. Upload the original file. <span class="sc-tag is-platform">Platform</span>
2. **Re-cut the opening.** A long-form YouTube intro rarely works in a swipe feed, where completion is the strong signal. <span class="sc-tag is-practitioner">Practitioner</span>
3. **Rewrite for the target action.** On X, a clip with a question people want to answer beats the same clip posted bare, because replies and quotes are weighted far above likes. <span class="sc-tag is-code">Code, applied</span>
4. **Don't fight the format.** Mostly-text Reels are on Instagram's own list of things that limit reach. <span class="sc-tag is-platform">Platform</span>
