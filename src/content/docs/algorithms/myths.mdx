**The short version:** most algorithm advice is recycled guesswork. Before you change how you work, check whether the claim traces to the platform's own code or explainers. Tap a claim to see what the source says.

<MythBuster />

## How to spot a bad claim

- **No source, or a screenshot of a source.** Real platform statements have a link and a date.
- **Exact numbers with no code behind them.** Only X publishes ranking weights. Anyone quoting precise weights for TikTok, Instagram or YouTube is guessing.
- **One-size-fits-all timing rules.** Feeds are personalized per viewer, so a universal "best time to post" is a weak lever at best.
- **A fix for sale.** If the person explaining the "secret" also sells the cure, treat it as an ad.
