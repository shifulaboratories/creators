## How we cover changes

- **Official first.** We start from the platform's own blog, help center, newsroom or engineering team. Anything we can only confirm through reporting is labeled **Reported**.
- **Dated.** Every update shows when the platform announced it and when it takes effect.
- **No rumor posts.** "My reach dropped, it must be the algorithm" isn't news. A named source with a link is.
- **Checked every day.** Get updates in any feed reader with the [RSS feed](/news/feed.xml), and see [Corrections](/about/corrections/) if we got something wrong.
