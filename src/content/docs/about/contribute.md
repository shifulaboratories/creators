Anyone can suggest a change. Every page has an **Edit page** link at the bottom that opens it on GitHub.

1. Fix a typo or outdated fact: click **Edit page**, make the change, and open a pull request.
2. Add or correct a tool: edit or add a file in `src/data/tools/`.
3. Write a new guide: open an issue first so a section editor can help shape it.

Read the full [contribution guide](https://github.com/byw1/creators-select/blob/main/CONTRIBUTING.md) and our [Editorial standards](/about/editorial-standards/).
