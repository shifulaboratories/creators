# Changelog

What changed on [creators.select](https://creators.select), newest first. The same notes are on the site at [creators.select/changelog](https://creators.select/changelog/) and as [GitHub Releases](https://github.com/shifulaboratories/creators/releases).

Versions follow [semantic versioning](https://semver.org) adapted for a website: see [docs/releasing.md](docs/releasing.md). Don't edit this file in a normal pull request. Add a note in `changes/` instead and it lands here at the next release.

## 0.7.0 · 2026-11-27 · Roadmap and changelog

You can now see what we're building and what just shipped.

### Added

- **Roadmap.** A public board at [/roadmap/](https://creators.select/roadmap/) showing what's being built now, what's next and what shipped, straight from our GitHub issues. Suggest something and it can land on the board.
- **What's new.** A dated list of every version of the site since the first one, at [/changelog/](https://creators.select/changelog/).

## 0.6.0 · 2026-11-26 · Spanish, Portuguese and free tools

The site speaks three languages, and the money tools got real numbers.

### Added

- **Spanish and Brazilian Portuguese.** The home page, Guides, menus and the first translated guides at /es/ and /pt-br/. (#41)
